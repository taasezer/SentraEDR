# SentraEDR Roadmap

To build a production-grade, lightweight Anti-RAT / EDR platform for Windows.

## Phases
1. **Phase 0:** Research & Planning (Current)
2. **Phase 1:** Workspace & Architecture Initialization
3. **Phase 2:** ETW Telemetry Engine
4. **Phase 3:** Process Monitoring Engine
5. **Phase 4:** Persistence Engine
6. **Phase 5:** Network Engine
7. **Phase 6:** Heuristic Detection Engine
8. **Phase 7:** Quarantine & Remediation Engine
9. **Phase 8:** Memory Inspection Engine
10. **Phase 9:** UI Dashboard
11. **Phase 10:** Testing Infrastructure

## Long-term Goals
- YARA Rule Engine Integration
- Machine Learning Anomaly Analysis
- Kernel-mode Extensions
- Distributed Telemetry Pipeline
